# Direct3D 11 (DX11)

**Short:** Microsoft's previous-generation Windows graphics API; an immediate-mode runtime where the driver manages resource state, validates commands, and hides queue submission behind a device context.

**Details:**

- The application talks to ``ID3D11Device`` (creation) and ``ID3D11DeviceContext`` (drawing). The immediate context submits commands directly; deferred contexts let secondary threads record ``ID3D11CommandList`` objects that the immediate context later replays.
- State is set with binders on the context: ``IASetVertexBuffers``, ``VSSetShader``, ``PSSetShaderResources``, ``OMSetRenderTargets``, ``RSSetState``. The driver tracks which state is dirty and applies it lazily on the next draw.
- Resource state (read / write / depth / present) is implicit: the driver inserts barriers and waits. This shifts work from the application onto the driver and is the main source of single-threaded CPU cost in DX11.
- Synchronization with the CPU goes through ``ID3D11Query`` (event / occlusion / timestamp); explicit GPU fences came later as ``ID3D11Fence``.
- Compute shaders, tessellation, geometry shaders, and stream output are all available. Ray tracing and mesh shaders are DX12-only.
