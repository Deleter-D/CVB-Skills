# Glossary

Reference glossary used by the Nsight Systems capability skills. Split into two sub-glossaries that follow different conventions and serve different purposes. When a term is unfamiliar, pick the sub-glossary that matches the context, then open the entry it lists.

## Sub-glossaries

- [graphics-glossary/index.md](graphics-glossary/index.md) - Tool-agnostic graphics-dev concepts: frames and timing, graphics APIs, ETW / WDDM, GPU, VSync, DX12, Vulkan, Stuttering, VidMm, and more.

- [nsys-glossary/index.md](nsys-glossary/index.md) — Nsight Systems-specific reference. Use to understand how an nsys report is structured and how to get data out of it, or which extraction path to use. It includes concepts like: analysis actions (recipes, export, stats, dumptimeline...), file formats, CLI commands, GUI / timeline elements, *.nsys-rep*, *export*, *recipe*, *timeline*, *parquet*, *nvtx*, *correlationId*, *thread state*, and more.
