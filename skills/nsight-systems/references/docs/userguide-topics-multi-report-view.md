## Multi-Report Timeline Views


#### Viewing Multiple Reports in Separate Panes

You have the option of looking at two or more Nsight Systems results files in
separate panes. To do so, open each in a tab. Grab one of the tabs and undock:


      :alt: One tab in gui is floating above the screen
      :class: image
      
When you hover with the cursor in the middle of the GUI, you will see options for
where to dock the pane:

      
      :alt: Arrows in the GUI show where you can dock the tab
      :class: image
      
Multiple reports can be docked in the window.      
      
      :alt: Picture of GUI with four reports docked.
      :class: image
      
      

#### Viewing Multiple Reports in the Same Timeline

You can open several reports in a single timeline. This could be done using one
of these methods:

-  **File > Open...** in the main menu, and select several report files.

-  **File > New multi-report view** in the main menu, add report files that you
   want to open in the Multi-report view, and click the "Apply" button.

      :alt: New multi-report view
      :class: image

Multi-report view contains simple editor that allows to add/remove some report
files and will load them all on a single timeline after applying that set of
reports.

      :alt: Multi-report-view
      :class: image

When reports are loaded, one can use the View Selector to open the Multi-report
view again, change the set of reports, and click on "Apply" button to reload the
timeline with the new set of reports.

The selected set of reports can be saved as a Multi-report view document and
could be opened later to load the same set again.
