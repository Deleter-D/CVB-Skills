# Common Analysis Pitfalls

This section collects common mistakes made when interpreting Nsight Systems
traces and when querying the exported SQLite database. The first subsection
covers domain-level misconceptions about GPU/CPU performance; the second covers
SQL traps specific to the Nsight Systems SQLite schema.
