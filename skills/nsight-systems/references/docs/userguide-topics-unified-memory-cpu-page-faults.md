#### Unified Memory CPU Page Faults

The Unified Memory CPU page faults feature in Nsight Systems tracks the page
faults that occur when CPU code tries to access a memory page that resides on
the device.

Note:

   Collecting Unified Memory CPU page faults can cause overhead of up to 70% in
   testing. Use this functionality only when needed.
