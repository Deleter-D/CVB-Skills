#### Launching GPU Metrics from the GUI

For commands to launch GPU Metrics from the CLI with examples, see
cli-profiling.

When launching analysis in Nsight Systems, select **Collect GPU Metrics**.

   :alt: GPU Metrics: GUI overview
   :class: image

Select the **GPUs** dropdown to pick which GPUs you wish to sample.

Select the **Metric set:** dropdown to choose which available metric set you
would like to sample.

   :alt: GPU Metrics: Metric sets
   :class: image

Note:
   Metric sets for GPUs that are not being sampled will be greyed out.
